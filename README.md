# אפליקציית שותפים – אב-טיפוס

אב-טיפוס לחיץ לאפליקציה לניהול דירת שותפים, מול משכירים ולחיפוש דירות ושותפים.

- קובץ אחד: `index.html` (HTML, CSS ו-JS בתוכו), בעברית מימין לשמאל.
- אין שרת ואין שלב build. כדי להריץ, פותחים את `index.html` בדפדפן.
- כל הנתונים הם נתוני דמה ונשמרים בדפדפן בלבד.

## מה יש באב-טיפוס

- **כניסה ובחירת תפקיד:** שוכר/ת, משכיר/ה או מחפש/ת דירה.
- **שוכר/ת:**
  - **הוצאות:** מאזן וחישוב "מי מעביר למי וכמה". אפשר לראות מצב ביניים או לבצע איפוס מלא, ויש קיזוז חודשי מדומה ב-31 בחודש.
  - **תורנויות:** סבב אוטומטי או בחירה חופשית.
  - **מד הדירה:** כל משימה שבוצעה שווה 10 נקודות, ואיור הדירה משתדרג בהדרגה לאורך 8 רמות (עציץ, מנורה, ספה, תמונה ושטיח, טלוויזיה, שרשרת אורות, חתול). כדי לעלות רמה צריך לאסוף את הנקודות של השלב, וגם שכל השותפים ישלימו בו לפחות משימה אחת.
  - **מול המשכיר/ה:** דיווח תקלות, חוזה וחשבונות.
  - **צ'אט דירתי:** כולל עוזר AI שמזהה הוצאה ומבקש אישור לפני רישום.
- **משכיר/ה:** מעקב שכירות, ניהול סטטוס תקלות, העלאת חשבונות וצ'אט. אין גישה לנתונים הפנימיים של השוכרים.
- **מחפש/ת דירה:** פילטרים קשיחים וגמישים, ופיד עם ציון התאמה. סוכן סינון עונה על שאלות מתוך מידע שפורסם במודעה ומעביר שאלות אחרות למפרסם.
- **הגדרות התראות:** חמישה סוגי התראות, שכל אחד מהם אפשר להפעיל או לכבות.

סוכן ה-AI מבוסס על חוקים פשוטים שרצים בדפדפן, וההתראות מוצגות בתוך המסך בלבד.
